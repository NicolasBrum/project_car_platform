# Contribuição

Este projeto utiliza Git Flow.

## Fluxo de trabalho

1. Atualize `develop`.
2. Crie uma branch `feature/<nome-curto>` a partir de `develop`.
3. Abra um pull request para `develop`.
4. Use `release/<versão>` para estabilização e integre em `main` e `develop`.
5. Use `hotfix/<nome-curto>` a partir de `main` e integre em `main` e `develop`.

Commits devem ser pequenos, focados e escritos no imperativo.
